# 故障工单关闭 / Fault work order closure

本手册适用于 EquipFlow 的故障工单结案，流程标识 EF-WO-CLOSE。

## 关闭前确认
确认维修处理已完成、设备试运行通过、报修人已经验收，并检查工单中的设备编号与现场设备一致。检查是否有遗留风险及未完成的处理项；存在未完成处理、试运行失败或验收未通过时，不得直接关闭，应保留处理中状态并补充阻塞原因。

## 关闭操作
1. 在“故障管理 → 故障工单”打开目标工单，核对编号及设备信息。
2. 填写故障现象、实际原因、处理措施、维修开始和结束时间，以及使用的备件。上传必要的维修记录和验收附件。
3. 在验收区域记录试运行结果、验收人员和验收日期。
4. 确认必填信息完整后，选择“提交验收”；由验收人员确认完成，再选择“关闭工单”。
5. 刷新页面核对关闭状态和关闭时间，并保留工单编号用于追踪。

## 注意事项
如果缺少关闭按钮，按权限申请流程联系系统负责人核查。本文描述操作流程，不证明某个用户当前有权限，也不代表某个工单已关闭。禁止填写虚假的验收结果。
