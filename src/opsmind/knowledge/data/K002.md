# 设备台账导出 / Equipment ledger export

本手册描述 EquipFlow 设备台账数据导出，功能标识 EQUIPMENT_LEDGER_EXPORT。

## 准备与操作
确认已获得设备台账查看和导出权限，明确数据用途及授权范围。
1. 打开“设备管理 → 设备台账”。
2. 设置基地、设备分类和使用状态筛选条件，执行查询并核对结果范围。
3. 点击“导出”，选择需要的字段，例如设备编号、名称、型号、所属基地和状态。
4. 确认导出范围，提交导出任务，在导出记录中下载生成的 CSV 文件。
5. 检查行数、字段和中文编码，按用途保存到获准的工作目录。

## 限制和例外
不要通过扩大筛选范围获取无关基地的数据。导出任务未完成时先查看任务状态，不要反复提交。缺少导出按钮时按权限申请流程提交用途和范围；本 SOP 不说明某个用户当前是否有权限，也不能替代实时导出任务状态查询。
