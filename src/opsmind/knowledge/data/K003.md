# 权限申请 / Access request procedure

适用 EquipFlow 设备台账查看、导出及其他业务角色申请，流程标识 EF-ACCESS-REQUEST。

## 申请设备台账权限
1. 在内部服务门户打开“应用权限申请”，选择 EquipFlow。
2. 填写申请人、部门、基地、业务用途、所需菜单或权限及使用期限。
3. 设备台账查看使用 EQUIPMENT_LEDGER_VIEW，导出能力需单独说明用途和范围。
4. 提交直属主管审批，再由系统负责人核对岗位职责和最小权限要求。
5. 审批完成后查看申请记录，按通知重新登录验证菜单；若仍不可见，提供申请编号供支持人员核查。

## 管理员权限
管理员权限应说明必要性、授权范围及有效期，并由系统负责人和安全负责人额外审批。不允许借用他人账号或绕过审批，提出申请并不代表自动获批。

## 边界
本文为稳定的申请流程，不能证明某个用户现有权限或缺失原因，也不执行授权修改。查询当前权限应使用实时权限查询能力。
