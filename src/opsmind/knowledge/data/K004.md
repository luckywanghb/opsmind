# 检验报告导出 / Quality inspection report export

本手册适用于 QualityHub，流程标识 QH-REPORT-EXPORT。

## 操作步骤
1. 在“质量检验 → 检验报告”输入检验批次，选择报告日期范围。
2. 核对物料编号、检验批次和报告审批状态，只允许导出已经审核的正式报告。
3. 点击“导出报告”，选择 PDF，确认报告版本及用途。
4. 下载后核对检验结论、报告编号和审核签名。

## 前置条件与限制
申请人须具备所属基地报告查看权限。未审核报告只能在系统中预览，不得作为正式质量证明。数据有误时联系检验负责人修订并重新审核，不得自行编辑导出的检验结论。此流程不适用于 EquipFlow 设备台账。
